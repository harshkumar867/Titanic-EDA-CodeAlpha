# Titanic Dataset Exploratory Data Analysis (EDA)

## Overview
This project performs exploratory data analysis on the Titanic dataset to understand factors affecting survival rates.  
We explore data structure, identify trends and anomalies, test hypotheses, and detect data quality issues.

## Dataset
Download the dataset here:  
[Kaggle Titanic Dataset](https://www.kaggle.com/c/titanic/data)  
Place `titanic.csv` in the project directory.

## Files
- `titanic_eda.ipynb`: Jupyter notebook with full analysis  
- `requirements.txt`: Python dependencies
